# متجر رونزي الإلكتروني — Ronzi Store

متجر إلكتروني عربي كامل + لوحة تحكم لإدارة المنتجات والمستخدمين.

## الملفات

| الملف | الوصف |
|---|---|
| `index.html` | صفحة المتجر — المنتجات، السلة، المفضلة، إتمام الطلب، الفاتورة |
| `login.html` | صفحة تسجيل دخول مستقلة للوحة التحكم |
| `admin.html` | لوحة التحكم — نظرة عامة، منتجات، مستخدمون، إعدادات |

## بيانات الدخول الافتراضية

```
اسم المستخدم: admin
كلمة المرور:  admin123
```

> **غيّرها فوراً** من قسم «المستخدمون» بعد أول دخول.

## طريقة التشغيل

1. نزّل الملفات في مجلد واحد.
2. افتح `index.html` بالمتصفح للمتجر، أو `admin.html` للوحة التحكم.
3. سجّل دخولك واستخدم الداشبورد مباشرة.

لا يحتاج سيرفر ولا تنصيب — كل المكتبات تُحمّل من الإنترنت (Tailwind + خط Cairo)، فلازم إنترنت.

## الصلاحيات

| الصلاحية | المنتجات | المستخدمون | الإعدادات |
|---|---|---|---|
| مدير عام (admin) | إضافة/تعديل/حذف | كامل | كامل |
| محرر (editor) | إضافة/تعديل | لا | تعديل |
| مشاهد (viewer) | قراءة فقط | لا | قراءة فقط |

## أساسيات اللوحة

- **المنتجات:** إضافة منتج (اسم، قسم، سعر، وصف، ألوان، شارة، تقييم)، تعديل، حذف، إظهار/إخفاء من المتجر.
- **المستخدمون:** إضافة حساب، تحديد الصلاحية، تفعيل/إيقاف، حذف.
- **الإعدادات:** اسم المتجر، رقم الواتساب، حساب شام كاش، كود الكوبون ونسبة الخصم، تغيير كلمة المرور.
- **النسخة الاحتياطية:** تصدير كل البيانات كملف JSON.

أي تعديل بالمنتجات أو الإعدادات يظهر في صفحة المتجر مباشرة، لأن الصفحتين تقرآن من نفس المصدر (`localStorage` ← `ronziData`).

## حدّ النسخة الحالية

البيانات محفوظة بمتصفح الجهاز فقط (localStorage)، يعني:

- التعديلات تُحفظ على جهازك انت، وتظهر لك في المتجر.
- زوار المتجر من أجهزتهم ما رح يشوفوا منتجاتك المُضافة.
- المشاركة بين المستخدمين تحتاج سيرفر + قاعدة بيانات (المرحلة القادمة).

كلمة المرور حالياً تُخزّن كنص واضح — مناسب للتجربة فقط، وليس للإنتاج.

## التقنيات

HTML + Tailwind (CDN) + JavaScript خالص — بلا أي اعتماديات أو خطوة بناء.
